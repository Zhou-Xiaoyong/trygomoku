白の鏡戦法を崩す：コピーが通用しなくなる時

2026-10-27 8 分で読了

五手目で、コピーはもう遅れている

この順に並べてください。黒 h8、白 i9、黒 h6。ここで白が鏡で h10 に置き、黒が h7 と受けます。

h列は h6、h7、h8 になり、h5 と h9 が空いたままです。二手でできた活三で、白の h10 はどちらの端も止めていません。止めるべき形より一行上にいるのは、鏡がそこに置いたからです。

五手。コピーが効かなくなる速さはこれだけです。

中央の石には鏡像がない

鏡の話はここから始まります。h8 は黒の石で、h8 の鏡像は h8 自身です。だから白は、釣り合いを取るはずのその点に永遠に入れません。盤を百八十度回すと、黒の中央の石は自分自身に戻ります。同じことができる白の石は一つもありません。

結果として黒は、白が複製できない四本の線を独占します。8行目、h列、そして中央を通る二本の長い斜めです。黒がこの四本の上で作る五は、白が応じられない石を一つ使っています。

斜めの応手が一直線の応手より優れる理由もここにあります。連珠では、白の二手目は h8 を中心とする 3×3 の中に置かなければなりません。八点あり、その八点はすべて上の四本のどれかの上です。g7 と i9 が一方の斜め、g9 と i7 がもう一方、g8 と i8 が8行目、h7 と h9 が h列です。中心線を取らずに済ませることはできないので、黒にとって高いほうを取ります。斜めに応じれば黒の斜めを一本潰せます。h9 にまっすぐ応じると、自分の石が黒の中央石と同じ列に並び、黒がすでに持っている石と組ませてしまいます。

距離2が分岐点

中心線上の黒石を鏡がどう扱うか、計算します。h8 を中心とした点対称で、その石は中心の反対側、同じ線の上、同じ距離に移ります。

  • 距離1。黒 i8、白は g8 を複製。8行目は g8、h8、i8 となり、白の石が片端を塞ぐので黒の二連は j8 だけが出口です。眠った三が精一杯。ここでのコピーは問題ありません。
  • 距離2。黒 h6、白は h10 を複製。黒が h7 と埋めて h6、h7、h8 を作り、両端の h5 と h9 が空きます。コピーはこの時点で活三に一手遅れています。
  • 距離3。黒 h5、白は h11 を複製。同じ形には h6 と h7 の二手が要り、その間に白が一手だけ割り込めます。

罠なのは真ん中だけです。そして実戦で出るのも真ん中だけです。距離2は、直開きの定石が黒の三手目を置く場所だからです。連珠で、黒の三手目が中央の 5×5 に収まる開局を直開きと呼びます。距離にして最大二。桂馬の間接開局はもっと外に置くので、鏡は二手だけ長生きします。

正確なコピーは使えない

中央と関係のない二つ目の失敗があります。黒 k6、白は e10 を複製。幾何学的には完璧です。距離も角度も相対位置も一対一で対応しています。ところが白の e10 は自分のどの石とも線になりません。黒の k6 は、黒が欲しかった場所にちょうど座っています。

コピーは距離を保ち、意図を捨てます。黒は自分の計画に合う石を選び、鏡は計算で白の石を選ぶ。八手進めば、規則に選ばれた八つの石が盤のあちこちに散らばります。

さらに悪いことに、複製した石は二度と動かせません。同じ線で近くに並んだ二つの石は、後から別々の脅威にはなれません。鏡がいちばん作りやすいのがこれです。整って見えて、何も換金できない形。

四は鏡写しにできない

仕組みとしてはここで終わりです。黒が四を作れば、白の応手は一つしかありません。止める。鏡の点も四になりますが、相手の五より後に来る四は無価値です。その石は打たれないまま残り、局面は対称でなくなります。

つまり鏡は黒の最初の四で死にます。黒の最初の四は最初の活三から生まれ、最初の活三は、白が複製を続けていれば五手目に出ます。三つの出来事がつながっていて、全部が黒の手番の中にあります。

白が打つべき一手

止める時期を選び、止める場所も選びます。合図は、黒が中心線の距離2に石を置いたことです。応手は鏡の点でも、素直な止めでもありません。h7 は黒の中央石にぴったり寄るだけで、白には何もつながりません。

その空点を一手早く取りに行きます。黒の新しい石と h8 の間の一点です。黒の活三がそこへ伸びたがっているのだから、先に取れば形になる前に死にます。代価は守りの石一つ。四手目に払ってください。六手目まで待つと間に合いません。

次の二手は黒がいない場所に使います。h列に三つ、8行目に二つ置いているなら、黒が持っているのは盤の中央の十字だけで、他は空です。12行目や c列の活三は、中央の石では止められません。その石はその線の上にいないからです。これが破り方です。相手の力が届かない場所で形を作ります。

打つ前に数えます。その点が相手の線を断ち、同時に自分の三を起こすなら打ちます。相手の線を断つだけなら、もう一度複製して待ちます。自分の三だけができて相手の活三が立っているなら、順序が逆です。

禁手表を武器にする

連珠には、天秤が逆に傾く形があります。黒は三三、四四、そして六連以上を打てません。白は三つとも打てて、六連でも勝ちです。

だから最良の破点は交点であることが多い。黒の二本の線が一つの空点で交わり、そこが白の欲しい点になっている。黒は打てば禁手、打たなければ負けです。白が石を一つ置けば、黒は自分の規則を避けて回り込むことになり、守りに使った手番が戻ってきます。

長連も同じ向きに効きます。破点の線にすでに白の石が四つあれば、五つ目は勝ちで、六つ目も勝ちです。黒の六つ目は負けです。そういう線に形を複製すれば、複製のほうが元よりも価値を持ちます。

盤の前に座ったら

  1. 二手目から四手目までは、複製してかまいません。まだ損はなく、読んでいる間は局面が締まります。
  2. 距離2を見張ります。黒の石が h8 から二点、8行目か h列か長い斜めの上に置かれた瞬間にコピーをやめます。
  3. その空点を取ります。相手の新しい石と中央の間の一点。石一つで構想ごと消えます。早く払ってください。
  4. そこからは軸の外で作ります。12行目、c列、g13 の斜め。中央の石が届かない場所ならどこでも。
  5. 止め点より先に禁手を見ます。相手の応手が三三なら、その手は打てません。白の三はすでに活三です。

白を持って五局、条件を一つだけ足します。四手目以降は鏡を使わない。最初の二局は頼りなく感じます。コピーは実際に楽だからです。四局目には、黒が打つ前に距離2の点が見えるようになります。技術はそれだけです。

黒の三手目を距離2に置く開局を知りたいなら、覚えておくべき十の開局に、それぞれが白に何を求めるかが書いてあります。破った後の白の打ち方は後手の戦略、中盤の手番の話は守りと攻めの切り替えにあります。

それから盤を開いて、自分から白を選び、四手目でわざと止めてください。局面が自分のものになる時刻が、はっきり早くなります。

四手目でコピーをやめる

自分から白を選び、五局、四手目以降は鏡を封印してください。局面は一度苦しくなり、それから自分のものになります。
